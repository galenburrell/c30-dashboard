Transformation log

    Monthly update

    1. Census publishes C30 on about the first business day of each month. Download privtime.xlsx, pubtime.xlsx, privsatime.xlsx and pubsatime.xlsx from census.gov/construction/c30/historical_data.html.
    2. Attach the four files in the Claude conversation that built this page and ask for an update, or run python3 build.py raw && python3 render.py from the pipeline folder.
    3. The build stops if any mapped column is missing or renamed, or if the four files come from different releases. It archives the files with SHA-256 hashes under vintages/<release>/ and lists every changed segment-month in the revisions table above.
    4. This page is republished to the same link. The prior release's numbers stay reproducible from its archived vintage.
